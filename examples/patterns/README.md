# Verified pattern library

Reusable UI motion patterns go here once they have evidence behind them — PLAN.md Phase 4.

A pattern belongs here only when it has: the source scene or project where possible, the exported Lottie/dotLottie, rendered preview frames, a validation report, and a runtime matrix listing which players it was actually tested on. Without those it is a sketch, not a pattern, and putting it here implies a confidence nobody has earned.

Templates and the known-good baseline fixture live with the skill, in `skills/lottie/assets/`, so that installing the skill brings them along.
